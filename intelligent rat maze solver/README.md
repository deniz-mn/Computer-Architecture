# Intelligent Rat - Maze Solver

A hardware implementation of a maze solving algorithm using SystemVerilog.

## 📋 Project Description

This project implements a digital system for solving a 16×16 maze using the **Depth-First Search (DFS)** algorithm. The system includes an "intelligent rat" that must navigate from the starting point (0,0) to the goal point (15,15).

### Features

- 16×16 maze (0 = free path, 1 = wall)
- DFS algorithm using Stack for backtracking
- State Machine with 19 states
- Final path stored in Queue
- Binary and human-readable path output

## 🔧 Usage

### Simulation with ModelSim

#### Method 1: Using compile.do script

1. Open ModelSim
2. Change to project directory:
   ```tcl
   cd /path/to/CA_CA1_Maze
   ```
3. Run the compile script:
   ```tcl
   do compile.do
   ```
4. Run simulation:
   ```tcl
   vsim -voptargs=+acc work.tb
   run -all
   ```

#### Method 2: Manual compilation

1. In ModelSim, create a new project or open existing project
2. Add all files from `src/` directory
3. Add `test/Test_Bench.sv`
4. Compile all files (right-click → Compile → Compile All)
5. Run simulation: `vsim work.tb`
6. Output will be saved in `data/result/result.txt`

### Setting Maze File

Configure the maze file in `src/Maze_memory.sv`:

```systemverilog
parameter FILENAME = "data/maps/solvable_mazes/solvable_maze_0/maze_0.txt";
```

Or use any maze file from `solvable_mazes/` or `unsolvable_mazes/` directories and update the path accordingly.

### Running Python Scripts

The project includes two helper scripts for visualization and result processing:

#### 1. Visualize Maze (`draw_maze.py`)

This script displays the maze graphically:
- Reads a 16×16 maze file
- Shows green cells (0 = free path) and red cells (1 = wall)
- Useful for understanding the maze structure before simulation

```bash
# Visualize a specific maze file
python scripts/draw_maze.py data/maps/solvable_mazes/solvable_maze_0/maze_0.txt

# Visualize other mazes
python scripts/draw_maze.py data/maps/solvable_mazes/solvable_maze_1/maze_1.txt
python scripts/draw_maze.py data/maps/unsolvable_mazes/unsolvable_maze_0/maze_0.txt
```

#### 2. Convert Path to Readable Format (`read_move.py`)

This script converts the binary output from simulation to human-readable directions:
- Reads `data/result/result.txt` (binary format: 00, 01, 10, 11)
- Converts to text format (up, right, left, down)
- Saves to `data/result/result_readable.txt`

```bash
# Convert using default files
python scripts/read_move.py

# Convert with custom input/output files
python scripts/read_move.py data/result/result.txt data/result/my_output.txt
```

## 📊 Maze File Format

The maze file must be a 16×16 matrix of bits:
- `0` = free path
- `1` = wall

Example:
```
0000110011101011
0110000111001011
...
```

### Test Cases

The project includes two categories of test mazes:

#### `solvable_mazes/` - Solvable Mazes
- Contains mazes that have a valid solution from (0,0) to (15,15)
- Each folder contains:
  - `maze_X.txt` - The maze file in binary format (16×16 grid)
  - `maze_X_waveform.png` - Simulation waveform showing signal behavior
  - `maze_X_solution_path.png` - Visual representation of the maze with annotated solution path
  - `maze_X_result_binary.txt` - Expected binary output (direction codes: 00, 01, 10, 11)
  - `maze_X_result_readable.txt` - Expected readable output (directions: up, right, left, down)
- These mazes should result in `Done = 1` after simulation

#### `unsolvable_mazes/` - Unsolvable Mazes
- Contains mazes that have **no solution** from (0,0) to (15,15)
- Each folder contains:
  - `maze_X.txt` - The maze file in binary format (16×16 grid)
  - `maze_X_waveform.png` - Simulation waveform showing signal behavior
  - `maze_X_no_solution.png` - Visual representation of the maze showing no solution exists
- These mazes should result in `Fail = 1` after simulation

**Usage:** Use mazes from `solvable_mazes/` to test successful path finding, and mazes from `unsolvable_mazes/` to test failure detection.



## 🎯 Output

### Simulation Results

The simulation produces two main outputs:

1. **Status Signals:**
   - `Done = 1`: Maze solved successfully (for `solvable_mazes/` test cases)
   - `Fail = 1`: No solution found (for `unsolvable_mazes/` test cases)

2. **Path Output** (only when `Done = 1`):
   - `data/result/result.txt`: Final path in binary format
     - `00` = up
     - `01` = right
     - `10` = left
     - `11` = down

### Converting Output

To convert binary path to readable format:
```bash
python scripts/read_move.py
```

This creates `data/result/result_readable.txt` with directions like:
```
right
right
down
down
...
```

**Note:** For unsolvable mazes (`unsolvable_mazes/`), no path file is generated in `data/result/` since `Fail = 1` is asserted instead.

## 📝 Modules

### Intelligent_Rat
Top module that connects Controller and Datapath.

### Controller
State Machine with 19 states that controls the maze solving flow.

### Datapath
Includes:
- Register X, Y (current position)
- Counter (direction enumeration)
- Stack (path storage for backtracking)
- Queue (final path storage)
- Add/Sub Unit (next position calculation)
