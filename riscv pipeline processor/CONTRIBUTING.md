# Contributing Guide

Contributions to this project are welcome! This document provides a brief guide for contributing to the project.

## How to Contribute

1. **Fork the project**: First, fork the project
2. **Create a Branch**: Create a new branch for your changes
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Make Changes**: Apply your changes
4. **Commit**: Commit your changes
   ```bash
   git commit -m "Add: description of changes"
   ```
5. **Push**: Push your changes
   ```bash
   git push origin feature/your-feature-name
   ```
6. **Pull Request**: Create a Pull Request

## Code Standards

- Use clear and descriptive naming
- Add helpful comments
- Format code and follow Style Guide
- Test code before committing

## Reporting Bugs

If you find a bug:
1. Create a new Issue
2. Describe what problem occurred
3. Write steps to reproduce the issue
4. If possible, add a test case

## Suggesting New Features

To suggest a new feature:
1. Create an Issue
2. Explain why this feature would be useful
3. If possible, provide an example or sample code

## Questions

If you have questions, you can:
- Create an Issue with "question" label
- Participate in Discussions
