# ModelSim Project Files

This document explains the ModelSim project files in this repository.

## File Types

### `.mpf` - ModelSim Project File
- **Purpose**: Contains project settings, file list, and compilation order
- **Usage**: Open this file in ModelSim to load the entire project
- **Main File**: `riscv_pipeline.mpf`

### `.cr.mti` - Compile Report
- **Purpose**: Contains compilation reports and warnings from ModelSim
- **Usage**: Automatically generated by ModelSim during compilation
- **Note**: These files are in `.gitignore` and are not tracked in Git

## Project Files

- **`riscv_pipeline.mpf`**: Main ModelSim project file
  - Contains all source files and their compilation settings
  - Can be opened directly in ModelSim: `File > Open > riscv_pipeline.mpf`

## Note

Old backup files and compile reports have been removed. Only the main project file `riscv_pipeline.mpf` is kept.

## Usage

To use the project in ModelSim:

1. Open ModelSim
2. Navigate to: `File > Open > riscv_pipeline.mpf`
3. The project will load with all source files

**Note**: The project file contains absolute paths. If you move the project, you may need to update the paths in the `.mpf` file or recreate the project in ModelSim.
